# JavaScript Fun Projects

A collection of small JavaScript projects and experiments.

## Structure

Each project lives in its own folder:

- `/weather-app/`

The root `index.html` acts as the project index and is deployed to Vercel.

## Adding a new project

1. Create a new folder in the root.
2. Add the project's `index.html`, CSS, JS, images, etc.
3. Add a project card to the root `index.html`.
4. Link to it with `href="./project-folder/"`.

Example:

```html
<a href="./calculator/">View Project</a>
```
